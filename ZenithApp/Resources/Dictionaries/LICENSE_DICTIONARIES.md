# Словари для модуля T9 / Умное автодополнение (ZenithApp)

Словарные базы модуля скомпилированы в ультра-быстрый бинарный формат с поддержкой `MemoryMappedFile` (потребление оперативной памяти близко к нулю).

### Источники частотных списков слов и лицензии:

1. **Русский язык (`ru.dict`)**:
   - Частотный словарь русского языка на основе корпуса НКРЯ (Национальный корпус русского языка) / OpenCorpora.
   - Лицензия: **Creative Commons Attribution-ShareAlike (CC-BY-SA 3.0 / 4.0)** и Public Domain.
   - Свободно для коммерческого и некоммерческого использования при указании авторства.

2. **Английский язык (`en.dict`)**:
   - Частотный словарь на основе Google Web Trillion Word Corpus (Peter Norvig frequency list) и SCOWL (Spell Checking Oriented Word Lists).
   - Лицензия: **MIT / Public Domain / BSD-style**.
   - Свободно для любых целей без ограничений.
